Connection & trading access

Sign in to IB Gateway. Live uses port 4001; paper uses port 4002. Keep one Gateway connected. To switch accounts, log out and switch in Gateway; Lens follows automatically.

For trading, open Configure → Settings → API → Settings, untick Read-Only API and apply. You can still view holdings with it ticked.
